## مرحلهٔ ۰ — آماده‌سازی محیط چت جدید (نیم ساعت)

**کار:**
1. zip `XGPedia_Handoff_Package` را در **پوشهٔ تازه** باز کن (قانون extract تازه!).
2. `pip install -e ".[render,dev]"` سپس `playwright install chromium`.
3. `.env` را از `.env.example` بساز و دو توکن را پر کن: `FOOTBALL_DATA_ORG_TOKEN` + سه متغیر `LLM_*`.
4. `python check_env.py` — همهٔ خطوط باید [OK] یا فقط [WARN] اختیاری باشند.

**معیار پایان:** `python -m pytest tests/ -q` → **97 passed** (بدون fail).

## مرحلهٔ ۱ — انتقال دارایی‌های برند داخل کارت (مرحلهٔ «الف» رودمپ)

جایگزینی لوکاپ متنیِ بازسازی‌شده در قالب با **SVG رسمی** برند.

**ورودی:** `brand/logo/svg/logo-white.svg` (موجود) · الگوی آمادهٔ `_crest_html` در `cards.py` برای data-URI.
**کار:**

2. متغیر قالب `brand_mono` برای حالت تک‌رنگ سفید (تست هر دو روی پس‌زمینهٔ Ink).
3. فاوآیکون/آواتار شبکه‌ها: از `logo-xg-*.svg` (110px) — فقط اتصال، فایل موجود است.

**معیار پایان:** رندر پست ۱ → لوگوی رسمی روی کارت در هر دو حالت دو‌رنگ/مونو؛ تست‌ها هنوز ۹۷ سبز + یک تست جدید که presence لوگو را چک می‌کند.

## مرحلهٔ ۲ — لایهٔ انتشار تلگرام (فصل ۷ — مهم‌ترین گپ)

`publishers/telegram_bot.py` الان استخوان‌بندی بدون اتصال است.

**ورودی:** ربات aiogram موجود · جدول posts · تصمیم‌های D11 (کانال+گروه+ربات، انتشار با تأیید).
**کار:**
1. ربات را به **DB واقعی** وصل کن (حذف DRAFTS درون‌حافظه‌ای؛ خواندن پست‌های validated از posts).
2. فلوی تأیید: `awaiting_approval` → ادمین approve/reject → `approved` → ارسال کارت PNG + کپشن به کانال → ثبت در `publishing_logs` و `moderation_logs` (schema موجود در `db.py`).
3. دستور CLI: `python run.py publish --post-id N --dry-run` (ارسال واقعی: بدون `--dry-run`).
4. dry-run اول: پیام به chat_id خودت؛ بعد کانال تستی.
5. تلگرام Markdown/HTML ایمن: escape متن LLM.

**معیار پایان:** یک پست از پست ۱ (یا پست جدید همان روز) با ربات به کانال تستی ارسال شد؛ رکورد publishing_logs ثبت شد؛ اجرای دوبارهٔ همان پست پیام تکراری نمی‌فرستد (idempotency). تست‌ها: ۹۷ + تست‌های جدید فلوی approval.
