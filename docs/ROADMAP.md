# رودمپ دارایی‌ها و ماژول‌ها — XGPedia

وضعیت: ۱۴۰۵/۰۸/۲۶ (2026-11-17). این سند «چه داریم / چه کم داریم / از کجا می‌آید» را برای
لایهٔ رندر کارت استودیو (`src/xgpedia/render/`) نگه می‌دارد. اصل معماری: **کد ماژول‌های
بی‌داده همین حالا کامل و محفوظ است**؛ با رسیدن داده فقط فکت‌ها پر می‌شوند و ماژول خودکار
در کارت ظاهر می‌شود — تغییری در قالب لازم نیست.

منبع طراحی: `tools/matchday_studio.html` (استودیوی مرجع — هر تغییری اول آنجا، بعد قالب).
