# XGPedia — سند جامع معماری، وضعیت فعلی (v0.23.0) و نقشهٔ راه آینده

## ۱. هویت برند و سیستم طراحی یکپارچه (Design System)
- **نام و شناسه**: `XGPedia` (`@XGPedia`) — رسانهٔ فارسی تحلیل داده‌محور فوتبال («عدد را API می‌دهد، متن را مدل می‌نویسد، تصویر را قالب HTML می‌سازد»).
- **پالت رنگ اصلی**:
  - پس‌زمینهٔ پایه (Midnight Navy): `#0D1730`
  - رنگ تاکیدی اصلی (Signature Crimson): `#E62E45` / `#FC0C26`
  - رنگ مکمل لوگو (Brand Navy): `#223D67`
  - متن روشن: `#F8FAFC` / `#E2E8F0` / `#94A3B8`
  - طلایی ویژه (High-Value +EV ≥ 8%): `#FBBF24` / `#FDE047`
  - سبز ارزش مثبت: `#34D399` | آبی آسمانی: `#38BDF8` | قرمز هشدار/منفی: `#FB7185`
- **تایپوگرافی محلی (آفلاین در `brand/fonts/`)**:
  - فارسی: `Vazirmatn` (400–900)
  - اعداد/کد: `JetBrains Mono`
  - انگلیسی/نمایشی: `Space Grotesk`
- **لوگوهای رسمی برداری (`brand/logo/svg/`)**:
  - `logo.svg` (رنگی اصلی: XG سرمه‌ای + PEDIA قرمز)
  - `logo-white.svg` (سفید کامل برای پس‌زمینه‌های تیره)
  - `logo-xg-red.svg` / `logo-xg-white.svg` / `logo-xg-navy.svg` (مونوگرام XG)
  - `logo-watermark.svg` / `logo-watermark-white.svg` / `logo-xg-watermark-white.svg`
- **فرمت‌های استاندارد خروجی**:
  - پست عمودی `4:5` (`1080×1350`) — تلگرام و فید اینستاگرام
  - استوری/ریلز/شورتس `9:16` (`1080×1920`)
  - بنر/یوتیوب `16:9` (`1920×1080`)

## ۲. وضعیت فنی فعلی (v0.23.0 — ۱۸۴ تست سبز)

### الف) معماری ماژولار کارت (`src/xgpedia/render/card_kit/`)
- **`base_shell.py`**: پوستهٔ واحد HTML/CSS برای همهٔ کارت‌ها (هدر ۲ خطی، صفت توصیفی خلاقانهٔ بازی، هیرو، گرید ۲ ستونهٔ ماژول‌ها، فوتر با `@XGPedia`، و تابع `validate_half_width_layout` برای اعتبارسنجی سخت‌گیرانهٔ جفت‌بودن ماژول‌های نیم‌عرض).
- **۷ ماژول پیش‌ازبازی (`PRE_MATCH_PRIORITY`)**:
  1. `radar` — رادار ۶ محورهٔ تاکتیکی
  2. `keyduel` — تقابل مهره‌های کلیدی (دیتا از FPL Official + football-data.org scorers + ESPN + Understat)
  3. `signals` — سیگنال‌های ارزش بازار (+EV) روی ۸ بازار (1, X, 2, 1X, X2, O2.5, U2.5, BTTS) با نمایش ۲ تا ۳ مورد برتر مثبت، افکت طلایی برای ≥8% و برچسب «ارزش منفی» برای مقادیر منفی
  4. `wave` — موج زمانی ۱۵ دقیقه‌ای xG (استخراج خودکار از تفکیک واقعی نیمه اول/دوم `E0.csv` + ESPN)
  5. `trend10` — روند xG در ۱۰ بازی اخیر با محور عمودی xG و اعداد صحیح هفته‌های واقعی فصل جاری
  6. `stats` — مقایسهٔ شاخص‌های فنی (xG / xGA / SOT)
  7. `poisson` — ماتریس احتمال دقیق نتیجه (Dixon-Coles 5×5)
- **۷ ماژول پس‌ازبازی (`POST_MATCH_PRIORITY`)**: `xgrace`, `shotmap`, `momentum`, `efficiency`, `toprated`, `motm`, `stats`.
- **قواعد کپشن**: `watchout` (پیش‌ازبازی) و `autopsy` (پس‌ازبازی) هرگز روی کارت نمی‌آیند و به کپشن منتقل می‌شوند؛ منبع به‌صورت هایپرلینک و بدون هش/جمع‌آوری نمایش داده می‌شود.

### ب) منابع دادهٔ رایگان و زنده (`src/xgpedia/providers/`)
- `football_data_org.py`: برنامهٔ بازی‌ها، تیم‌ها، گلزنان (`/v4/competitions/PL/...`).
- `football_data_couk.py`: نتایج فصل (`E0.csv`)، ضرایب بازار (`fixtures.csv` شامل 1X2 و O/U 2.5) و موج ۱۵ دقیقه‌ای (`compute_wave_from_csv`).
- `fpl_free.py`: API رسمی و رایگان Fantasy Premier League (`bootstrap-static` بدون کلید API، شاخص Opta xG+xA) برای `keyduel`.
- `espn_free.py`, `understat.py`, `the_odds_api.py`: منابع پشتیبان رایگان.
- `live_intel_free.py`:
  - `fetch_live_coach_wikipedia`: استخراج زندهٔ سرمربی فعلی از Infobox ویکی‌پدیا + نام فارسی از `langlinks` + دیکشنری `config/team_venues.json` + آوانویسی خودکار فارسی (هرگز انگلیسی یا هاردکد نمی‌ماند).
  - `fetch_match_breaking_news`: دریافت اخبار مهم ۷ روز اخیر دو تیم از Google News RSS و BBC Sport RSS و تزریق به `MatchFacts.recent_news` برای پوشش خودکار تغییر سرمربی/مصدومیت/محرومیت در کپشن.
- `irib_conductor.py`: تشخیص خودکار پخش زنده از کنداکتور `tv3.ir` و `varzeshtv.ir`.

### ج) روتر هوشمند رایگان هوش مصنوعی (`src/xgpedia/editorial/llm_provider.py` و `src/xgpedia/media/free_media.py`)
- **متن (LLM)**: ترتیب اولویت `gemini-4-hydrogen` → `gemini-4-neon` → `gemini-3.8-flash` → `gemini-3.6-flash` → پشتیبان‌های Pollinations, GitHub Models, AxForge, Cerebras, SambaNova, OpenRouter, Cohere, Mistral, NVIDIA NIM, Cloudflare, Z.ai و پشتیبان‌های بدون کلید (OVHcloud, Kilo Code, LLM7.io).
- **کنترل تاخیر 429/503**: قابلیت تنظیم مدل شروع (`LLM_START_INDEX` در `.env` یا دکمهٔ `⚙️ تنظیم مدل شروع هوش مصنوعی` در تلگرام ذخیره در SQLite) + کول‌داون خودکار ۱۵ دقیقه‌ای + تایم‌اوت ۲۲ ثانیه.
- **تصویر و ویدیو رایگان (`free_media.py`)**: روتر چندارائه‌دهنده (Pollinations FLUX/Wan، Hugging Face، Cloudflare، NVIDIA، و ساخت ویدیوی محلی با FFmpeg).

### د) ربات تلگرام تعاملی (`src/xgpedia/publishers/telegram_bot.py`)
- کیبورد ثابت تاشو (`ReplyKeyboardMarkup`) + منوهای اینلاین + تایم‌اوت ۹۰ ثانیه + ۳ بار تلاش خودکار + دکمهٔ `🔁 ارسال مجدد پیش‌نمایش` بدون ساخت مجدد.
- کاستومایزر تعاملی: نام کامل ماژول در ردیف تمام‌عرض + ردیف کنترل فشرده (`عرض ۱/½`، `⬆️ بالا`، `⬇️ پایین`) + پیش‌نمایش شماتیک مکانی `<pre>` + جلوگیری از ساخت هنگام وجود جای خالی نیم‌عرض.
- تولید مجدد متن (`regen_txt`)، ویرایش متن با توضیح ادمین (`edit_txt`) و زمان‌بندی انتشار ۲۴ ساعته به وقت تهران (`HH:MM`).

## ۳. نقشهٔ راه ادامهٔ مسیر (Roadmap برای چت جدید)

### فاز ۱ — گسترش کارت‌های جدید و ماژول‌های مستقل (با هویت بصری واحد `card_kit`)
- افزودن قالب‌های جدید روی همان `base_shell.py` و `MODULE_REGISTRY` تا هر ماژول هم ترکیبی و هم تکی قابل خروجی‌گرفتن باشد:
  - **کارت جدول و کورس قهرمانی/سقوط** (`standings_race`: امتیاز، xPts، اختلاف عدالت آماری)
  - **کارت تقابل‌های رو‌در‌رو** (`h2h_history`: ۵ تقابل اخیر، میانگین گل و xG)
  - **کارت ترکیب احتمالی و غایبان** (`lineup_injuries`: چینش زمین + مصدومان و محرومان)
  - **کارت ستارهٔ هفته / مقایسهٔ دو بازیکن** (`player_spotlight` / `player_vs_player`)
  - **کارت عدد روز / رکورد هفته** (`number_of_day`: مینیمال و وایرال برای اینستاگرام و X)
  - **کارت خلاصهٔ هفته (Matchweek Wrap-up)**: بهترین حمله، بدشانس‌ترین تیم (xG vs Goals)، تیم منتخب هفته.

### فاز ۲ — هویت بصری اختصاصی و دارایی‌های گرافیکی
- **پک آیکون‌های SVG اختصاصی (`brand/icons/`)**: آیکون‌های یکدست برای توپ، استادیوم، سوت، کارت زرد/قرمز، مصدومیت، کاپیتان، رادار، تاج طلایی +EV و شبکه‌های اجتماعی.
- **لوگوهای اختصاصی زیربرندها**: ساخت نسخه‌های سازگار با لوگوی اصلی برای زیرمجموعه‌ها (مثلاً `XGPedia Light`، `XGPedia Iran`، یا کانال‌های تک‌تیم/تک‌لیگ).
- **خط تولید عکس بازیکن‌ها**: حذف پس‌زمینه خودکار + نورپردازی دوگانه (سرمه‌ای/قرمز یا رنگ تیم) + قاب استاندارد برای کارت‌های `keyduel` و `motm`.
- **پوسترهای ویژهٔ اختصاصی**: قالب خودکار برای دربی‌ها، فینال‌ها، روز مسابقه (Matchday)، نتایج سنگین و رکوردها با لوگوی برداری اصلی.

### فاز ۳ — تحلیل عمیق‌تر، جذاب‌تر و روایت‌محورتر
- ارتقای لایهٔ تحریریه (`editorial/prompt.py`) به چند لحن قابل انتخاب: **تحلیلی عمیق (اصلی)**، **لایت و سریع (طرفداری)**، **رشته‌توییت X** و **اسکریپت ویدیوی ۶۰ ثانیه‌ای (Reels/Shorts)**.
- استخراج خودکار زوایای جذاب (Narrative Hooks): تیم‌های بیش‌عملکرد/کم‌عملکرد نسبت به xG، نوارهای برد/باخت، اولین بازی سرمربی جدید، تقابل با تیم سابق.
- افزودن نظرسنجی تعاملی خودکار (Poll) زیر پست‌های پیش‌بازی در تلگرام/بله/ایتا.

### فاز ۴ — راه‌اندازی دیتای فوتبال ایران (لیگ برتر خلیج فارس)
- ساخت پرووایدر اختصاصی `src/xgpedia/providers/iran_pgpl.py`:
  - دریافت جدول، برنامه، نتایج و آمار پایه از منابع عمومی (مانند FotMob / SofaScore / Varzesh3 / جدول پخش IRIB).
  - نگاشت کامل نام فارسی/انگلیسی، لوگوها، ورزشگاه‌ها و سرمربیان ۱۶ تیم لیگ برتر ایران در `config/iran_teams.json`.
  - مدل برآورد xG بومی (Proxy xG) بر پایهٔ شوت، شوت در چارچوب، موقعیت‌های بزرگ و قدرت حمله/دفاع خانگی و خارج از خانه تا همان ماژول‌های `card_kit` برای لیگ ایران هم کار کنند.

### فاز ۵ — کانال‌های لایت، طرفداری تک‌تیم و تک‌لیگ (Multi-Channel Engine)
- معماری چندکاناله (`config/channels.yaml`): تعریف چند کانال مختلف از روی یک هستهٔ کد واحد؛ هر کانال با:
  - فیلتر اختصاصی (مثلاً فقط منچستریونایتد، فقط لیگ ایران، یا کانال لایت با متن کوتاه‌تر و ساده‌تر)
  - پالت رنگ و واترمارک اختصاصی
  - توکن/شناسهٔ کانال مجزا و زمان‌بندی مستقل.

### فاز ۶ — انتشار عکس و ویدیوی گل‌ها و هایلایت‌ها + ریلز/شورتس خودکار
- ساخت موتور ویدیوساز خودکار (`src/xgpedia/media/video_pipeline.py` با FFmpeg + Playwright):
  - تبدیل کارت‌های استاتیک به ویدیوهای ۱۵–۳۰ ثانیه‌ای متحرک (انیمیشن نمودار xG Race، اسلایدشوی پیش‌بازی با موزیک پس‌زمینهٔ بدون کپی‌رایت).
  - قالب کاور و واترماک خودکار روی کلیپ‌های گل و خلاصه بازی‌ها (با رعایت ذکر منبع و استانداردهای پلتفرم‌ها).

### فاز ۷ — انتشار خودکار چندپلتفرمی (Omnichannel Publishers)
ساخت پوشهٔ `src/xgpedia/publishers/` با آداپتور استاندارد `PublisherAdapter` برای انتشار همزمان از یک دکمه:
1. **پلتفرم‌های داخلی ایران**:
   - **بله (Bale)**: ساده‌ترین اتصال (API تقریباً همسان با Bot API تلگرام — قابل پیاده‌سازی در ۱ روز).
   - **ایتا (Eitaa)**: اتصال مستقیم از طریق سرویس رسمی ایتایار (`eitaayar.ir/api`).
   - **روبیکا (Rubika)**: اتصال از طریق Bot API / پنل کانال روبیکا.
   - **آپارات (Aparat)**: آپلود خودکار ویدیوهای تحلیل، خلاصه و انیمیشن‌های xG از طریق API آپارات.
2. **پلتفرم‌های بین‌المللی**:
   - **تلگرام (Telegram)**: فعال و آماده.
   - **اینستاگرام (Instagram)**: انتشار خودکار Feed (`4:5`)، Stories (`9:16`) و Reels از طریق Instagram Graph API.
   - **یوتیوب (YouTube)**: انتشار خودکار YouTube Shorts (`9:16`) و ویدیوهای تحلیلی (`16:9`) با YouTube Data API v3.
   - **ایکس (X / Twitter)**: تبدیل خودکار تحلیل به رشته‌توییت (Thread) همراه با کارت تصویری از طریق X API v2.
   - **تیک‌تاک (TikTok)**: انتشار ویدیوهای عمودی کوتاه (`9:16`) از طریق TikTok Content Posting API (هم‌زمان با Reels و Shorts).
3. **پلتفرم‌های پیشنهادی اضافه برای رشد سریع‌تر**:
   - **تردز (Threads)**: همگام‌سازی بسیار راحت کنار اینستاگرام (رشد ارگانیک بالا برای محتوای کوتاه ورزشی).
   - **کانال واتساپ (WhatsApp Channels)**: دسترسی مستقیم و نرخ دیده شدن فوق‌العاده بین مخاطبان فارسی‌زبان فوتبال.
   - **وب‌سایت / بلاگ سبک (`XGPedia.ir` یا Substack/Ghost)**: آرشیو سئو‌شدهٔ تحلیل‌ها برای جذب مخاطب دائمی از گوگل.
   - **کست‌باکس / شنوتو (پادکست کوتاه ۲ دقیقه‌ای پیش‌بازی)**: تبدیل خودکار متن تحلیل به ویس فارسی با TTS برای مخاطبان در رفت‌وآمد.

### فاز ۸ — انتقال به کلود ۲۴/۷ (بدون نیاز به کامپیوتر شخصی)
- افزودن `Dockerfile` (مبتنی بر ایمیج رسمی Playwright) + اندپوینت سبک `/health` برای اجرا روی Oracle Cloud Always Free / Google Cloud / Render / VPS لینوکس.
