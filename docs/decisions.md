- **انتقال به کپشن:** متن «باید حواسشون بهش باشه» (`watchout`) و «روایت آماری و گره تاکتیکی بازی» (`autopsy`) هرگز روی کارت نمایش داده نمی‌شوند و به‌صورت خودکار در متن کپشن قرار می‌گیرند.
- **خودبسندگی و ضدسرریز:** فونت‌های محلی و CSS پشتیبان Tailwind درون HTML خروجی جاسازی می‌شوند، لینک‌های خارجی CDN حذف می‌شوند و نیم‌فضاهای خالی (`orphan half-width`) به‌صورت خودکار تمام‌عرض می‌شوند.
