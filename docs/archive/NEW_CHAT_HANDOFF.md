## ۰) پروژه در یک پاراگراف

XGPedia = خط تولید محتوای فوتبال داده‌محور فارسی (لیگ برتر انگلیس): **عدد را API
می‌دهد، متن را مدل زبانی می‌نویسد، تصویر را قالب HTML می‌سازد، انتشار را زمان‌بند
انجام می‌دهد.** هفت لایه: Provider → Normalization → Analytics → Editorial (LLM+۷
دروازه) → DB (SQLite) → Render (HTML→PNG سه‌فرمته) → Publish (تلگرام با تأیید
انسانی). معماری کامل: `docs/HANDOFF.md` §۲.
