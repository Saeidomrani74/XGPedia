# پوشهٔ قالب‌های استودیویی XGPedia (`studio_templates/`)

این پوشه منبع اصلی طراحی کارت‌های XGPedia است. هر فایل HTML که با ساختار استودیو در این پوشه قرار بگیرد، **عیناً و بدون هیچ تغییر طراحی** توسط موتور رندر (`src/xgpedia/render/studio_engine.py`) خوانده می‌شود و با دیتای واقعی مسابقه پر می‌گردد.

## فایل‌های فعال

| نام فایل | نوع کارت (`post_type`) | توضیح |
|---|---|---|
| `pre_match.html` | `preview` / `pre_match` | قالب استودیویی کارت پیش‌ازبازی |
| `post_match.html` | `post_match` | قالب استودیویی کارت پس‌ازبازی |

## نحوهٔ به‌روزرسانی یا افزودن قالب جدید

1. کافی است فایل HTML جدید استودیو (با همان ساختار بوم `#ea` و وضعیت `S` / `draw()` یا `R()`) را با نام `pre_match.html` یا `post_match.html` جایگزین فایل قبلی در همین پوشه کنید.
2. هیچ نیازی به ویرایش کد پایتون برای تغییر رنگ‌ها، فونت‌ها، سایه‌ها یا جزئیات طراحی نیست؛ رندرر در زمان تولید هر کارت، فایل HTML همین پوشه را می‌خواند، فونت‌های محلی `brand/fonts/` را به‌صورت خودبسنده تزریق می‌کند، دیتای واقعی مسابقه را جایگذاری می‌کند و فقط ماژول‌هایی را نمایش می‌دهد که دیتای کامل و معتبر دارند.

## ترتیب اولویت ماژول‌ها (انتخاب خودکار)

- **پیش‌ازبازی:** رادار ۶ محوره ← تقابل مهره‌های کلیدی ← سیگنال‌های ارزش (+EV) ← موج ۱۵ دقیقه‌ای ← روند ۱۰ بازی اخیر ← مقایسه شاخص‌های فنی ← ماتریس پواسون ۵×۵.
  *(متن «باید حواسشون بهش باشه» روی کارت نمی‌آید و به‌صورت خودکار در کپشن قرار می‌گیرد.)*
- **پس‌ازبازی:** نمودار جریان امید گل (xG Race) ← نقشه شوت ← موج فشار ۵ دقیقه‌ای ← دقت ضربه و دروازه‌بان‌ها ← برترین‌های زمین ← ستاره زمین (MOTM) ← آمار کلیدی مسابقه.
  *(متن «روایت آماری و گره تاکتیکی بازی» روی کارت نمی‌آید و به‌صورت خودکار در کپشن قرار می‌گیرد.)*
